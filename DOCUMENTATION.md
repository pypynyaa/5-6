# Документация проекта

## Структура проекта

Проект разделен на три основных модуля:

### 1. Common (Общий модуль)
Расположен в директории `common/`
- Содержит общие классы и интерфейсы, используемые как клиентом, так и сервером
- Основные компоненты:
  - `exceptions/` - пакет с исключениями
    - `ScriptRecursionException.java` - исключение для обработки рекурсии в скриптах
  - `interfaces/` - пакет с интерфейсами
  - `mainClasses/` - пакет с основными классами данных
  - `shit/` - пакет с вспомогательными классами

### 2. Client (Клиентский модуль)
Расположен в директории `client/`
- Отвечает за взаимодействие с пользователем и отправку команд на сервер
- Основные компоненты:
  - `ClientMain.java` - точка входа клиентского приложения
  - `network/TCPClient.java` - реализация TCP-клиента
  - `userManagers/` - классы для работы с пользовательским вводом
    - `HumanInputHelper.java` - помощник для ввода данных о человеке
    - `UserInputScanner.java` - сканер пользовательского ввода

### 3. Server (Серверный модуль)
Расположен в директории `server/`
- Обрабатывает команды от клиента и управляет коллекцией
- Основные компоненты:
  - `ServerMain.java` - точка входа серверного приложения
  - `commands/` - пакет с реализациями команд
  - `managers/` - пакет с менеджерами
    - `CollectionManager.java` - управление коллекцией
    - `CommandManager.java` - управление командами
  - `network/TCPServer.java` - реализация TCP-сервера

## Конфигурация сборки

### Общий pom.xml
- Определяет общие настройки проекта
- Указывает версию Java (11)
- Содержит общие зависимости
- Настраивает плагины для сборки

### Client pom.xml
- Наследуется от общего pom.xml
- Зависимости:
  - common (общий модуль)
  - junit (для тестов)
- Плагины:
  - maven-compiler-plugin (компиляция)
  - maven-jar-plugin (создание JAR)
  - maven-shade-plugin (создание исполняемого JAR)

### Server pom.xml
- Наследуется от общего pom.xml
- Зависимости:
  - common (общий модуль)
  - log4j-api и log4j-core (для логирования)
  - junit (для тестов)
- Плагины:
  - maven-compiler-plugin (компиляция)
  - maven-jar-plugin (создание JAR)
  - maven-shade-plugin (создание исполняемого JAR)

## Процесс работы

### Клиентская часть
1. Запуск клиента (`ClientMain.java`)
2. Инициализация TCP-клиента
3. Чтение команд от пользователя
4. Валидация и сериализация команд
5. Отправка команд на сервер
6. Получение и отображение ответов

### Серверная часть
1. Запуск сервера (`ServerMain.java`)
2. Инициализация TCP-сервера
3. Загрузка коллекции из файла
4. Ожидание подключений
5. Обработка команд от клиентов
6. Сохранение изменений в файл

## Сетевое взаимодействие

### TCP-клиент
- Устанавливает соединение с сервером
- Отправляет сериализованные команды
- Получает и десериализует ответы
- Обрабатывает ошибки соединения

### TCP-сервер
- Принимает входящие соединения
- Читает команды от клиентов
- Обрабатывает команды через CommandManager
- Отправляет результаты клиентам
- Использует неблокирующий режим работы

## Обработка команд

### Структура команды
- Каждая команда представлена объектом
- Содержит тип команды и аргументы
- Реализует интерфейс Executable

### Процесс выполнения
1. Получение команды от клиента
2. Валидация команды
3. Выполнение через соответствующий класс команды
4. Формирование ответа
5. Отправка результата клиенту

## Логирование

### Настройка Log4j2
- Конфигурация в `log4j2.xml`
- Уровни логирования:
  - INFO: основная информация
  - ERROR: ошибки
  - DEBUG: отладочная информация

### Логируемые события
- Запуск/остановка сервера
- Подключение клиентов
- Выполнение команд
- Ошибки и исключения

## Запуск приложения

### Сервер
```bash
cd server
java -jar target/server-1.0-SNAPSHOT-shaded.jar
```

### Клиент
```bash
cd client
java -jar target/client-1.0-SNAPSHOT-shaded.jar
```

1. Использование Stream API для обработки коллекции
2. Сериализация объектов для передачи
3. Неблокирующий режим работы сетевых каналов
4. Модульная архитектура
5. Логирование всех важных событий
6. Обработка ошибок и исключений
7. Валидация пользовательского ввода
